# Обучение волнами

Сюда команда `python3 tools/rychag.py learn wave` складывает предложения по улучшению работы: `proposals-<дата>.md` для чтения и `.json` для программы. В `history.jsonl` пишется, какие предложения были подготовлены, применены или отклонены.

Ничего не применяется само. Предложение вступает в силу только после `learn apply <код>`. Отзыв руководителя сам по себе не меняет статус утверждения, вывода или записи базы знаний и не создаёт факт. Урок, который считается доказательством, возникает только из фактического результата решения.
