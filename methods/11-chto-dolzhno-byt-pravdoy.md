# 11. Что должно быть правдой

## Когда применять

Этап 5. Построить не меньше трёх по-настоящему разных вариантов, среди них «оставить как есть» и «закрыть направление», и для каждого выписать, что должно быть правдой, чтобы он оказался лучшим.

**Когда не применять:** диагноз не готов (нет действующего вывода вида cause или finding); человек уже выбрал вариант (тогда 12 и 13).

## Что нужно на входе

- Действующие выводы этапа 4: `rychag conclusion list`.
- Рамки руководителя: деньги, срок, что трогать нельзя.
- Рамки не названы: `rychag question add --text "Есть ли рамки по деньгам и сроку на исправление?" --if-yes "отбрасываю варианты за рамками" --if-no "показываю варианты с ценой каждого"`.

## Шаги

1. Набросай варианты широко, пока без спора «правда ли это». Варианты отличаются по сути (что меняем и для кого), а не размером одного шага: «вернуть 14 дней» и «вернуть 10 дней» это один вариант.
2. Обязательные варианты: «оставить как есть» (что будет через 3 и 6 месяцев, если ничего не делать) и «закрыть направление» (что сэкономим, что потеряем, куда уйдут люди). Если закрыть нельзя по сути, напиши одной строкой почему.
3. Для каждого варианта выпиши 3-5 условий: что должно быть правдой про людей, про деньги, про конкурентов, про нашу способность это сделать.
   Пример (вымышленный) для «вернуть 14 дней пробного периода»: падение у новых вызвано сроком, а не ценой; доля ушедших без оплаты вырастет не больше чем на 5 п.п. (процентных пункта); команда меняет срок за неделю.
4. У каждого условия отметь, что о нём известно: факт (C...), гипотеза или «нет данных». Самое сомнительное условие варианта выдели: его проверка решает судьбу варианта.
5. Запиши варианты в реестр, у каждого основания:
   `rychag conclusion add --kind option --text "Оставить как есть: падение новых продолжится" --rests-on C004,C005`
   `rychag conclusion add --kind option --text "Закрыть направление: сэкономим на поддержке, потеряем выручку новых" --rests-on C021,C023`
   `rychag conclusion add --kind option --text "Вернуть 14 дней пробного периода новым" --rests-on C002,K002`
6. В `options.md` под каждым вариантом: заголовок с кодом, суть, условия, самое сомнительное условие. Возражения пишет критик по 12.
7. Сравни варианты по самым сомнительным условиям: у какого они правдоподобнее. Это предложение, а не выбор. Остановка 3: выбирает человек. После выбора `rychag stage next`.
8. Сравнение для руководителя веди для одной клиентской ситуации и одного срока, по пяти признакам: ожидаемая польза; число клиентов, которым она доступна; затраты; срок первых результатов; последствия ошибки. Разные варианты часто решают разные части проблемы и требуют разного объёма работ: скажи это прямо.
9. Ответь, что выигрывает клиент за дополнительные деньги компании. Если дешёвый вариант даёт почти ту же пользу, назови наблюдение, которое оправдает переход к дорогому. Если ни один вариант пока нельзя обоснованно выбрать для широкого запуска, предложи самую короткую проверку, которая изменит решение.

## Шаблон результата

`options.md`, для каждого варианта:
```
## K010 Оставить как есть
Суть: ...
Должно быть правдой: 1) ... (C...) 2) ... (гипотеза C...) 3) ... (нет данных)
Самое сомнительное условие: ...
Возражение: ...   (пишет критик, 12)
```
Сводная таблица в `options.md` и в части документа о выборе:
```
Ситуация: ...   Срок сравнения: ...
| Вариант | Польза для клиента | Скольким клиентам доступна | Затраты | Срок первых результатов | Что будет, если ошиблись |
Что клиент получает за дополнительные деньги: ...
К дорогому варианту переходим, если увидим: ...
```

## Чем проверяется

`rychag verify --layer 4`: вариантов вида option не меньше трёх, в тексте одного есть слова «оставить как есть», у каждого в `options.md` есть строка «Возражение:». Вариант «закрыть направление» программа не требует: его наличие проверяешь сам. Насколько варианты различаются по сути, видит только критик.

Вопросы себе: если убрать формулировки, видно ли, что варианты разные; что должно быть правдой для «оставить как есть»; какое одно наблюдение сразу убило бы мой любимый вариант.

## Частые ошибки

- Три варианта это один вариант в трёх размерах.
- «Оставить как есть» для галочки, без последствий в числах.
- Условия общие («рынок примет») вместо проверяемых.
- Агент выбирает сам вместо остановки для человека.
- Варианты сравнены для разных ситуаций или разных сроков.
- Альтернатива такая, которую никто всерьёз не стал бы рекомендовать.

## Основание

Для каждого варианта выписать, что должно быть правдой, и пересматривать, когда условие перестаёт выполняться: Roger Martin (<https://rogerlmartin.substack.com/p/2022-08-22_what-would-have-to-be-true-83dac5bd2189html>). Обязательные «оставить как есть» и «закрыть направление»: требование задания, наша сборка.
