# 12. Почему провалится

Прочитай файл `methods/12-pochemu-provalitsya.md` целиком (путь от корня репозитория) и действуй строго по нему: там шаги, команды записи, шаблон результата и проверка. Не пересказывай методику по памяти, единственный источник это файл.

Команды пишутся как `rychag ...`, это `python3 tools/rychag.py ...`. Задач несколько: добавляй `--project <имя>`. Общие правила работы лежат в `AGENTS.md`.
