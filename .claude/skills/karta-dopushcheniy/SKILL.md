# 10. Карта допущений

Прочитай файл `methods/10-karta-dopushcheniy.md` целиком (путь от корня репозитория) и действуй строго по нему: там шаги, команды записи, шаблон результата и проверка. Не пересказывай методику по памяти, единственный источник это файл.
