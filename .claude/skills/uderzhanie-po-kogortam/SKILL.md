# 05. Удержание по когортам

Прочитай файл `methods/05-uderzhanie-po-kogortam.md` целиком (путь от корня репозитория) и действуй строго по нему: там шаги, команды записи, шаблон результата и проверка. Не пересказывай методику по памяти, единственный источник это файл.
