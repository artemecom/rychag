# 20. Запись решения и условия пересмотра

Прочитай файл `methods/20-zapis-resheniya-i-peresmotr.md` целиком (путь от корня репозитория) и действуй строго по нему: там шаги, команды записи, шаблон результата и проверка. Не пересказывай методику по памяти, единственный источник это файл.

Команды пишутся как `rychag ...`, это `python3 tools/rychag.py ...`. Задач несколько: добавляй `--project <имя>`. Общие правила работы лежат в `AGENTS.md`.
