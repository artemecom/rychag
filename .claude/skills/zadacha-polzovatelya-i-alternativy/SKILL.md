# 06. Задача пользователя и альтернативы

Прочитай файл `methods/06-zadacha-polzovatelya-i-alternativy.md` целиком (путь от корня репозитория) и действуй строго по нему: там шаги, команды записи, шаблон результата и проверка. Не пересказывай методику по памяти, единственный источник это файл.
