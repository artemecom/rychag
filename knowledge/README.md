# База знаний отрасли

Правила и наблюдения из открытой практики операторов связи и смежных отраслей мира, плюс уроки самого агента. У каждой записи есть источник, дата, слой близости и статус. Записи это ориентиры: они подсказывают гипотезы, варианты и рекомендации и никогда не являются фактами о продукте, который разбирается.

## Что где лежит

- `records.jsonl`: записи B001, B002... (одна строка JSON на запись).
- `sources/KS001.txt` и `KS001.meta.json`: сохранённые копии источников (адрес, дата публикации, дата обращения, sha256).
- `INDEX.md`: создаётся командой `kb index` (сама запускается после добавления, импорта, отзыва и замены).
- `rejected.jsonl`: записи, которые импорт отклонил, с причиной.

## Запись

Поля: правило (`rule`), когда применимо (`applies_when`), когда не применимо (`not_when`), темы, метки, место (страна, компания), вид (`правило`, `наблюдение`, `урок`), сила (`независимый-замер`, `данные-компании`, `мнение`), слой близости 2-5 (`layer`), источник и дословная цитата, число (должно быть в цитате). Слой 1 здесь не бывает: это данные самого продукта, они живут в проекте. Урок агента не требует источника, помечается как урок и годится только для гипотезы.

Записи не удаляются: `kb retire` ставит статус «отозвана», `kb replace` ставит «заменена», с датой и причиной.

## Команды

`kb source add`, `kb add`, `kb import`, `kb search "слова"` (запись подходит, если совпала хотя бы половина значимых слов запроса, все при одном-двух словах; порядок: ближний слой, число совпавших слов, сила, дата; у каждого результата печатается, сколько слов совпало), `kb show`, `kb link`, `kb list`, `kb stale`, `kb retire`, `kb replace`, `kb stats` (как используются записи: ориентиры, выводы, отзывы, фактические результаты), `kb index`. В проекте запись становится утверждением: `claim add --type benchmark --kb B012 --text "..."`.

## Формат файла импорта

Одна строка JSON на запись: `rule`, `applies_when`, `not_when`, `themes`, `tags`, `place`, `date_published`, `url`, `title`, `source_file`, `quote`, `number`, `strength`, `kind`, `layer`. Файл с текстом источника лежит в папке, которую называют ключом `--sources-dir`.

## Дата публикации

Допустимы `ГГГГ`, `ГГГГ-ММ` и `ГГГГ-ММ-ДД`. Значение хранится как задано, а для свежести берётся последний день названного периода. Пустая дата даёт предупреждение, а не отказ.

## Карта причин и обучение

Карта причин лежит в `knowledge/map/` (описание: `knowledge/map/README.md`), команды `map ...`. Уроки из фактических результатов попадают в базу командой `learn apply` (вид «урок»), см. `learn/README.md`.
