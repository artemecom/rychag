# Карта причин

Карта показывает, что на что влияет: например, рост цены усиливает отток абонентов. Каждая связь держится на записях базы знаний. Связь без действующих записей остаётся гипотезой и знанием не считается.

## Узлы: nodes.jsonl

Одна строка JSON на узел: `id` (N001, N002...), `name` (название по-русски), `kind` (`показатель`, `фактор` или `действие`), `aliases` (другие названия, необязательно). Добавить: `python3 tools/rychag.py map node add --name "Отток абонентов" --kind показатель --alias "уход,потеря"`.

## Связи: links.jsonl

Одна строка JSON на связь: `id` (R001...), `from` и `to` (коды узлов), `sign` (`усиливает` или `ослабляет`), `conditions` (при каких условиях верно), `evidence` (список кодов записей базы знаний), `layer` (самые близкие данные среди записей: 1 данные самого продукта, 2 данные компании, 3 другие компании в России, 4 компании в мире, 5 смежные отрасли), `strength` (самая сильная из записей), `status` (`действует`, `гипотеза`, `отозвана`), `note`. Слой, силу и статус программа считает сама. Если действующих записей не осталось, связь становится гипотезой.

Добавить: `python3 tools/rychag.py map link add --from "Цена тарифа" --to "Отток абонентов" --sign усиливает --conditions "после повышения" --evidence B012,B031`. Повтор той же тройки «откуда, куда, знак» объединяется: записи добавляются к существующей связи.

## Формат файла импорта

Команда `python3 tools/rychag.py map import файл.jsonl`. Одна строка JSON на объект, поле `type` обязательно. Узлы лучше писать выше связей.

```
{"type":"node","name":"Отток абонентов","kind":"показатель","aliases":["уход","потеря"]}
{"type":"node","name":"Цена тарифа","kind":"фактор"}
{"type":"link","from":"Цена тарифа","to":"Отток абонентов","sign":"усиливает","conditions":"после повышения без предупреждения","evidence":["B012","B031"],"note":"по данным операторов"}
```

В `from` и `to` можно писать код узла или его название (псевдоним). Записи в `evidence` должны существовать и действовать. Отклонённые строки попадают в `knowledge/map/rejected.jsonl` с причиной.

## Команды

`map node add|list`, `map link add|list|retire`, `map import`, `map causes "показатель"`, `map effects "фактор"`, `map path "A" "B"`, `map check`, `map export --format mermaid`. Рисунок карты: `knowledge/map/map.mmd` (сплошная стрелка: действует, пунктир: гипотеза).
