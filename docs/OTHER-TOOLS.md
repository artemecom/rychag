# Другие программы с ИИ: что работает и что проверено

Агент «Рычаг» это папка с текстовыми инструкциями и одна программа на Python (`tools/rychag.py`). Поэтому суть работы не зависит от программы с ИИ. От неё зависит только то, какие дополнения репозитория она подхватит сама: замок завершения, навыки, помощники, подключение MCP.

Честная оговорка. Единственное, что здесь проверено запуском, это сама программа `tools/rychag.py`, её тесты, сервер MCP (собственным пробным клиентом на Python) и генератор навыков. Из перечисленных ниже программ с ИИ запускалась одна: Claude Code (записанные прогоны без окна и живой прогон 22.11.2026 в обычном окне, задача `svyaz-test`). Остальные не запускались. Колонка «Читает» это описание из документации программ, а не результат запуска. Всё, чего я не запускал, помечено «не проверено».

## Что делать в любой программе

1. Откройте папку репозитория как рабочую.
2. Отправьте первое сообщение из таблицы. Если программа не читает `AGENTS.md` сама, слово «прочитай» в сообщении это заменяет.
3. Положите свои файлы в `projects/<задача>/materials/` до того, как просите агента ими пользоваться: программа может запретить ему копировать файлы из-за пределов папки.
4. Перед тем как принять результат, выполните `python3 tools/rychag.py gate` сами (если заказчик задал структуру результата, замок включает и `doc check`). Это то же самое, что в Claude Code делает замок завершения. Проверка работает одинаково в любой программе, потому что это обычный запуск Python.

## Что не зависит от программы

Правила «нет цитаты, нет числа», «одна страница без воды», слои близости доказательств, статусы выводов, база знаний и карта причин живут в `tools/rychag.py` и проверяются тестами репозитория. Там же живёт всё, что нужно для брифа заказчика с заданной структурой результата: документ по частям (`doc init`, `doc check`, `doc page`), запись допущения (`claim add --type assumption`), готовые расчёты (`calc ready`) и место требования в результате (`req close --where`). Они одинаковы везде. Не одинаков только способ, которым программа с ИИ узнаёт о правилах и запускает проверку: в Claude Code частично автоматически, в остальных вручную по сообщению выше.

## Как пополнить таблицу

Запустили программу сами: поменяйте в строке статус на «проверено» и допишите, что именно запускали, на какой версии и что получилось. Без запуска статус «не проверено» не меняется.
