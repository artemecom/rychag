# Ключевые решения

Таблица отвечает на четыре вопроса по каждой детали: какое решение принято, зачем, что ломается без него и чем проверено. Решения 32-38 приняты по брифу заказчика (`оформление/мегафон/бриф-заказчика/бриф-мегафон.txt`, страницы указаны в строках). Основание остальных решений: записка `оформление/общее/решения-и-правки/2026-11-18-мегафон-выводы-из-исследования.md` (выводы из исследования о том, как сильные команды строят агентов). Её главный вывод: агента делает сильным проверка, которую нельзя уговорить, а не число методик или помощников.

Как читать последнюю колонку. «Проверено» стоит только там, где есть автоматический тест (имя теста указано, запуск: `python3 -m unittest discover -s tests`) или записанный прогон. Всё остальное честно названо «не проверено», даже если решение выглядит разумным.

## Чего мы не знаем

- Почти все цифры лидеров рынка, на которые опирается записка, измерены самими компаниями.
- Замеров пользы критика на аналитических задачах и пользы проверки свежести данных нет, это наши меры.
- Что руководители лучше решают по одной странице, измеренным результатом не подтверждено, это практика.
- Бриф заказчика агент прошёл целиком один раз (задача `svyaz-dlya-blizkih`: первый проход и семь кругов правок, 26,67 USD). Четыре независимые сверки по карте брифа из 121 строки дали 87, 97, 98 и 97 выполненных строк; в сравнении вслепую с ответом обычного чата на тот же бриф один проверяющий поставил 113 против 112 (охват равный, документ агента сильнее в деньгах и воспроизводимости чисел, ответ чата легче читается и стоит 0,75 USD). Последняя версия документа после точечных правок независимо не сверялась. Повторяемость на втором таком же брифе не проверена.
- Замок завершения есть только в Claude Code. В других программах тот же скрипт запускают вручную (`python3 tools/rychag.py gate`).
