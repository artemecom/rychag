# Материалы, на которые ссылается описание работы

Здесь лежат рабочие материалы демонстрации по брифу заказчика. Они нужны, чтобы числа из описания можно было проверить.

- `versii-dokumenta/`: версии документа агента с третьей по восьмую. Восьмая совпадает с `projects/svyaz-dlya-blizkih/document.md` до правки одной подписи на первой странице, сделанной после итоговой сверки. Первые две версии отдельными файлами не сохранялись.
- `sverki/`: карта брифа из 121 строки, полные тексты независимых сверок третьей и пятой версий и сводка всех сверок с таблицами «что внесено в агента».
- `sravnenie-s-chatom/`: запрос обычному чату, его ответ, сверка ответа и сравнение двух документов вслепую одним проверяющим.

Тексты сверок и ответ чата написаны нейросетями и сохранены как есть: правила оформления папки на них не распространяются.
