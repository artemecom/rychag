# Сравнение агента с обычным чатом на брифе заказчика

Дата: 21.11.2026. Требование конкурса: показать, что агент полезнее обычного чата, замером, а не словами.

## Как сравнивали

1. Тот же бриф отдан той же модели (Sonnet 5.5) одним сообщением, без папки агента, без личных настроек и без инструментов. Запрос: `запрос-чату.txt`, ответ: `ответ-чата-1.md`. Ответ пришёл за 9 минут и стоил 0,75 доллара по прайс-листу.
2. Документ агента: седьмая версия стратегии по брифу (первый проход и шесть кругов правок, 24,62 доллара).
3. Оба документа под буквами А и Б отданы одному независимому проверяющему. Он не знал, кто автор, и оценивал каждую из 121 строки карты брифа сразу для обоих документов по заранее записанным правилам. Полный разбор: `сравнение-вслепую.md`.

Что в этом сравнении нечестно в пользу агента: его документ прошёл шесть кругов правок по замечаниям руководителя и независимых сверок, а чат отвечал один раз. Первую версию агента (один проход, 3,50 доллара) другой проверяющий оценил в 87 выполненных строк из 121. Одной меркой с ответом чата первую версию не сравнивали.

## Что получилось

| Мерка | Агент | Обычный чат |
|---|---|---|
| Строки карты брифа: выполнено, частично, нет | 113, 8, 0 | 112, 9, 0 |
| Ловушки брифа (13): прямых попаданий | 0, три места на грани | 0 |
| Принятые значения без пометки «допущение» | 0 в тексте, 5 только в расчётах | 14 |
| Допущения с диапазоном и способом проверки | 22 из 22 | 9 из 13 |
| Одно число в разных местах разное | 3, все оговорены в тексте | 8, не оговорены |
| Числа, которые нельзя воспроизвести | 0 расчётных | 9 |
| Просьба руководителю в рублях | да, с диапазоном и наибольшей потерей | нет, только человеко-месяцы |
| Честно сказано, что цели года не достигаются | да | да |
| Связь с проблемой клиента из брифа | слабее | сильнее |
| Читаемость | тяжелее: много точных сумм и пометок | легче: короткие абзацы, но много сокращений |
| Стоимость | 24,62 доллара | 0,75 доллара |

## Вывод

По охвату требований брифа агент и обычный чат равны: разница в одну строку меньше погрешности мерки. Агент не «знает больше» и не пишет полнее.

Отличие в другом. Документ агента можно подписать: в нём названа сумма, наибольшая потеря на каждом этапе и правило остановки с числом, каждое число пересчитывается приложенным расчётом, а свои расхождения документ называет сам. В ответе чата половина просьбы тратится до решения, о котором просят, срок главного ответа не выходит из собственных чисел документа, а рублей нет вовсе.

Цена этого отличия: в 33 раза дороже и шесть кругов правок с участием человека и независимых проверяющих. Чат сильнее в том, что читается легче и держится одной клиентской проблемы.

Чего этот замер не показывает: разброса (сравнивался один ответ чата и один документ агента), пользы агента на задачах с настоящими данными, где есть что проверять по источникам, и того, как отработал бы чат после тех же шести кругов правок.
