# Демонстрационный проект: бриф «Связь для близких и собственных устройств»

Здесь видно, что агент «Рычаг» сделал на одном примере: какую задачу получил, с какими материалами работал и какой результат отдал руководителю. Использованы только открытые данные: бриф заказчика, опубликованный для конкурса.

## 1. Задача руководителя

Кому из клиентов помочь в первую очередь, что именно изменить и почему оператору стоит вложить в это деньги. Нужен план на ближайший год и ориентир на конец третьего года.

- Постановка задачи: [brief.md](brief.md)
- Требования брифа, выписанные с дословными цитатами (75 требований): [requirements.json](requirements.json)

## 2. Исходные материалы, которые получил агент

- Бриф заказчика, 11 страниц: [materials/brief-zakazchika.txt](materials/brief-zakazchika.txt)

Данных о клиентах в брифе нет. Поэтому всё, чего в нём не хватает, агент записал допущениями: у каждого диапазон, обоснование, способ проверки и значение, при котором решение меняется.

## 3. Итог: стратегии в читаемом виде

Бриф требует один документ из пяти частей, поэтому обе стратегии лежат в одном файле.

- **Страница для руководителя (читается за пять минут):** [page.md](page.md)
- **Полный документ:** [document.md](document.md)

| Что искать | Где в документе |
|---|---|
| Продуктовая стратегия: первые клиенты, проблема, предложение, состав первого запуска, путь организатора и участника | Начало документа, часть 1 «Клиент и его проблема», часть 2 «Предложение и путь к клиенту» |
| Коммуникационная стратегия: обещание клиенту, что мешает понять или выбрать, чем подтверждаем обещание, ключевое сообщение, тексты на пути клиента, роль каналов | Часть 2 «Предложение и путь к клиенту» |
| План проверки: что проверяем в первом квартале, размер групп, правило решения | Часть 3 «Польза для клиента и прибыль оператора» |
| Экономика: прибыль года, окупаемость по кварталам, допущения | Часть 3 |
| Варианты и план по кварталам, прогноз по показателям | Часть 4 «Стратегический выбор и план по кварталам» |
| Люди, зависимости, риски, просьба руководителю | Часть 5 «Ресурсы, риски и решение руководителя» |

## 4. Что ещё лежит в папке

| Файл или папка | Что это |
|---|---|
| [options.md](options.md) | Варианты и возражения критика к каждому |
| [decisions/](decisions) | Записи решений: владелец, показатель, дата и условие пересмотра |
| [analysis/](analysis) | Параметры расчётов. Все расчёты выполняет программа |
| [ledger/](ledger) | Реестр утверждений: факты с цитатами, расчёты, допущения, выводы с основаниями |
| [sources/](sources) | Сохранённые копии источников, по которым программа сверяет цитаты |
| journal.jsonl | Журнал всех шагов агента |

## 5. Как проверить самому

Команды запускаются из корня репозитория, нужен только Python 3.9.

```
python3 tools/rychag.py status --project svyaz-dlya-blizkih
python3 tools/rychag.py verify --project svyaz-dlya-blizkih
python3 tools/rychag.py doc check --project svyaz-dlya-blizkih
python3 tools/rychag.py req list --project svyaz-dlya-blizkih
python3 tools/rychag.py claim assumptions --project svyaz-dlya-blizkih
```

Вторая демонстрация по тому же брифу, проведённая с человеком и показанная в видео, лежит в папке [../svyaz-test](../svyaz-test).
